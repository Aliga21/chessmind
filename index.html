绑定 Lichess 账号

粘贴你的 Lichess 个人 API 令牌（在此创建，勾选 preference:read 即可）。令牌仅保存在本机浏览器，不会上传到任何服务器。

绑定的作用：显示你的资料与等级分、一键拉取你的公开研讨列表。不绑定也可以用「公开研讨」和「粘贴 PGN」导入。

从 Lichess 流式拉取该账号的历史对局（按时间倒序，服务器限速约 20 局/秒），自动判定结果、匹配「我执」，导入后即可批量分析。重复对局会自动跳过，可随时取消，已导入部分保留。

对局数量很多时注意浏览器本地存储上限（约 5MB）：空间不足时自动保留最近导入的部分，可用「拉取范围」缩小数量。
